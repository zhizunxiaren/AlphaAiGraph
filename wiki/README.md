# AlphaAiGraph LLM Wiki

This directory follows the LLM-maintained wiki pattern from Karpathy's `llm-wiki` gist.

- `raw/`: immutable source notes or references curated by the user.
- `pages/`: LLM-maintained markdown pages, concept notes, summaries, and syntheses.
- `index.md`: content-oriented catalog for finding wiki pages.
- `log.md`: append-only chronological record of ingests, queries, and lint passes.

`AGENTS.md` remains the project schema and operating convention file for this repository.
